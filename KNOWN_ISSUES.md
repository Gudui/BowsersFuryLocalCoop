# Known issues

- This release targets Bowser's Fury version 1.1.0 only.
- Some boss, cutscene, 2D, and cross-area transitions remain less tested than ordinary exploration.
- Luigi input and camera behavior can be affected by other controller or executable mods.
- Atmosphere support is experimental and has not been validated as broadly as Ryujinx.
- The settings file is read at scene initialization; edits do not retroactively change a loaded scene.
